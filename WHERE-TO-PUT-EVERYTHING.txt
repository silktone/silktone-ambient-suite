WHERE TO PUT EVERYTHING — Silktone Ambient Suite
================================================

Just drag each file into the folder next to it. No installer, no Terminal.

Silktone Ambient.component — Home > Library > Audio > Plug-Ins > Components
Silktone Ambient.vst3 — Home > Library > Audio > Plug-Ins > VST3
Silktone Ambient.app — Applications (or anywhere you like; double-click to open)
Silktone Vocal Channel.component — Home > Library > Audio > Plug-Ins > Components
Silktone Vocal Channel.vst3 — Home > Library > Audio > Plug-Ins > VST3
Silktone Vocal Channel.app — Applications (or anywhere you like; double-click to open)

What each one is:
- .component is the Audio Unit, for Logic Pro.
- .vst3 is the VST3 version, for other music apps that use VST3.
- .app is the Standalone version. It opens by itself, no music app needed.

How to find the Library folder in your home folder:
The Library folder is hidden. In Finder, hold down the Option key, click
the Go menu at the top of the screen, then click Library. Then open Audio,
then Plug-Ins, then Components (or VST3).

Pro Tools: there is no Pro Tools (.aaxplugin) version of these plugins
yet. If one is made later, it goes in Macintosh HD > Library >
Application Support > Avid > Audio > Plug-Ins.

Presets: nothing to place.
The presets are already built into the plugins, so there is nothing
separate to put anywhere for those.

After you drop the files in, quit Logic and open it again, and the
plugins will show up under Silktone.
